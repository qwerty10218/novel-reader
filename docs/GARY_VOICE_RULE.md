# Gary 個人敘事偏好

本文件是《彼岸仍是人間》後續續寫與修稿的公開接續規則，用來把 Gary 的個人手感轉譯進小說，而不是複製散文腔。

## 核心句

讀者想追小顧，不想聽旁白講解小顧。

## 寫作規則

- 用問題推進，不用結論壓人。
- 抽象感必須落到動作或物件上。
- 允許人物笨拙、自嘲、岔氣、不漂亮。
- 浪漫可以存在，但不能救人。
- 留白由行為、對話、沉默、物件、半句話生成，不由旁白標註。
- 先刪保險旁白，再補人物行動。

## 修稿檢查

- 這一段是小顧在推動，還是旁白在替他講？
- 這句話能不能改成一個問題、一個動作、一個停頓？
- 讀者是否會想知道小顧下一步做什麼？
- 是否出現「他後悔了」「他忽然明白」「這意味著」等作者保險句？

## 禁忌

- 不把小顧寫成現代散文旁白者。
- 不用漂亮句子教讀者怎麼看留白。
- 不反覆強調同一情緒或同一象徵。
- 不在動作已經成立後，再補一段心理說明。
