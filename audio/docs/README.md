# 彼岸

《彼岸》是小說《彼岸仍是人間》的閩南語主題曲。

音樂以暗色調 Indie Folk Rock 為基底，融合閩南祭典聲響、祭典鼓、鑼與嗩吶。

編曲核心不是單純追求磅礡，而是強調行進感、留白、克制與逐步推進的宿命感。

傳統元素不是裝飾，而是歌曲節奏與敘事的一部分。
